# Clothing Image Classification Using HOG and Linear SVM

Pattern Recognition course project using the Fashion-MNIST dataset.

## Project Goal

The goal of this project is to investigate image classification using
feature extraction and machine learning techniques.

## Methods

- Raw Pixel Features
- HOG Feature Extraction
- Linear Support Vector Machine (SVM)
- PCA (optional)

## Dataset

Fashion-MNIST

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Scikit-image
